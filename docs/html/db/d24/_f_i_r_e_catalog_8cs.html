struct FIRE::FIRECatalog::FILE_ID_INFO

Marshalled structure for retrieving file ID information from Windows NTFS.

This structure receives output from the Windows API call GetFileInformationByHandleEx with FileInfoByHandleClass.FileIdInfo, and contains the volume serial number and file ID.
