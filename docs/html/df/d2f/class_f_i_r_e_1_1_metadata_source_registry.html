Detailed Description

Registry for registered metadata sources.

MetadataSourceRegistry maintains a collection of available IMetadataSource implementations and provides lookup by source name. It is used during the collection phase to retrieve the appropriate metadata extractor for each configured keyword.

Default Sources: When created, the registry automatically registers two built-in sources:

  • FileInfoMetadataSource as "FILEINFO"
  • ExifToolMetadataSource as "EXIFTOOL"

Custom Sources: Additional sources can be registered via Register, allowing custom metadata extractors for proprietary or specialized file formats.

Case-Insensitive Lookup: Source names are stored and looked up case-insensitively, so "exiftool", "EXIFTOOL", and "ExifTool" all refer to the same source.

Looking up a metadata source:

var registry = new MetadataSourceRegistry();
var source = registry.GetSource("EXIFTOOL");
if (source != null)
{
var metadata = source.ExtractMetadata("photo.jpg");
}
